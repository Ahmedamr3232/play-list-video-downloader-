Zero Friction Setup

Ready in less than 60 seconds

Send this link to any friend — they can set it up in 3 simple steps without touching the command line.

01

Download & Extract the Tool

Download the project ZIP from GitHub and extract it anywhere on your computer (e.g. your Downloads or Desktop folder).

Download Latest ZIP
02

Double-Click setup.bat

Double-click setup.bat. It automatically checks Python, installs yt-dlp, configures FFmpeg, and creates a shortcut on your Desktop!

setup.bat ← Automated 1-click installer
03

Load Extension into Chrome / Edge

1. Open Chrome and go to chrome://extensions
2. Toggle ON Developer mode (top-right corner)
3. Click Load unpacked and select the extension folder.

chrome://extensions → Load unpacked

That's it! You're ready to download.

Double-click the Start YT-DLP Server icon on your Desktop anytime you want to use the extension.
